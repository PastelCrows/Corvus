# software-center/ — Phase 6

GUI-first software center (Flatpak backend) and networking GUI.

Covers:
- App install/update/remove through a GUI, no terminal required
- NetworkManager GUI front end: wifi, VPN, network profiles
- Dev toolchain availability (compilers, runtimes, version control)
  installable through the same GUI (see `devtools/`)

See `docs/SCOPE.md` §5, §8, and §11.

Status: not started.
