# installer/ — Phase 5

Graphical installer and first-run setup wizard — most new users' first
impression of the OS, needs to not feel like an Arch install.

Covers:
- Partitioning, user account creation, hardware detection during install
- First-run wizard: account/preferences setup, no terminal touched
- Out-of-the-box branding/theming
